# Shoot Plan · 拍摄策划网站

一个从零构建的拍摄策划工具：开篇确定主题 / 服装 / 风格 / 道具 / 时间 / 地点，中篇以分镜图片呈现，并支持按 **道具（含多道具组合）、景别、方向、角度、焦距、构图、光位** 七个维度排序与筛选，每张图下方附神态 / 动作注释。

## 功能特性

- **七维分镜排序**：道具、景别（远/全/中/近/特写）、方向（正/斜侧/侧/背）、角度（平/仰/俯）、焦距（广角/中焦/长焦）、构图（居中/三分线/留白/对称/框架/引导线/对角线/前景）、光位（逆光/侧逆光/正侧/前侧/顺/柔光兜底）
- **编辑能力**：修改任意分镜内容、插入新图（AI 自动识别属性后手动确认，或纯手动填写）
- **AI 自动策划**：输入主题或上传参考图 → 自动生成多组拍摄方向（每组 ≥4 张）→ 确认后搜索 20 张图并撰写完整策划；也可跳过选方向，直接按上传的图片写策划
- **多图源聚合**：Bing / Unsplash / Openverse / 自定义图源；支持导入小红书笔记配图
- **长图导出**：一键将整份策划合成为一张 1240px 宽的长图
- **多凭据管理**：支持 DeepSeek 官方 API 或任意 OpenAI 兼容端点，凭据本地保存、随时切换；多模态（视觉）模型可独立指定
- **数据本地持久化**：策划数据存 localStorage，上传图片存 IndexedDB，刷新不丢失

## 快速开始

```bash
# 方式一：Windows 双击 start.bat

# 方式二：命令行
node server.js
```

然后浏览器打开 <http://localhost:4173>。

> 无需 npm install——服务端为 Node 原生实现，零第三方依赖（Node 18+）。

## 模型配置

进入页面右上角「设置」：

1. 选择预设（DeepSeek）或自定义 OpenAI 兼容端点
2. 填入 API Key；DeepSeek 推荐文本模型 `deepseek-v4-pro`、视觉模型 `deepseek-flash`（支持图像理解）
3. 点击「测试读图」自检视觉链路

图片识别、策划撰写等 AI 能力均通过本地服务端代理转发，Key 不经过第三方。

## 目录结构

```
server.js          # 静态服务 + API 代理（LLM / 图源聚合 / 小红书解析 / 图片缓存代理）
start.bat          # Windows 一键启动
public/
  index.html
  css/app.css
  js/
    core.js        # 维度常量、状态、localStorage/IndexedDB 持久化
    ai.js          # LLM 调用、图片识别、策划生成
    wizard.js      # AI 自动策划向导（4 步）
    search.js      # 图源搜索
    xhs.js         # 小红书笔记导入
    view.js        # 渲染 / 编辑 / 上传
    settings.js    # 凭据与设置
    exporter.js    # 长图导出
    demo.js        # 演示数据
    app.js         # 入口
```
